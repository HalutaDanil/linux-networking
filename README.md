# Linux Network Configuration

> Настройка сетевой инфраструктуры на виртуальных машинах

## О проекте

Проект по конфигурированию сети между несколькими виртуальными машинами: роутерами и рабочими станциями. Реализована полноценная сетевая топология с DHCP, NAT, файрволом и туннелированием.

## Сетевая топология

```
                    ┌─────────┐
                    │  ws22   │
                    │ (Apache)│
                    └────┬────┘
                         │
    ┌─────────┐     ┌────┴────┐     ┌─────────┐
    │  ws11   │◄───►│   r1    │◄───►│   r2    │
    │ (DHCP)  │     │(роутер) │     │(роутер) │
    └────┬────┘     └────┬────┘     └────┬────┘
         │               │               │
    ┌────┴────┐     ┌────┴────┐     ┌────┴────┐
    │  ws21   │     │   ws21  │     │   ws22  │
    │(статика)│     │(статика)│     │(статика)│
    └─────────┘     └─────────┘     └─────────┘
```

## Что настроено

| Компонент | Технологии |
|-----------|-----------|
| **IP-адресация** | Статические IP через `netplan` |
| **DHCP** | `isc-dhcp-server` на роутерах |
| **NAT** | `iptables` + `sysctl` (ip_forward) |
| **Файрвол** | Bash-скрипты для управления правилами |
| **Apache** | Веб-сервер на ws22 |
| **Туннелирование** | SSH local/remote forwarding |
| **Анализ трафика** | `tcpdump`, `telnet`, `iperf3` |

## Ключевые конфиги

- `/etc/netplan/*.yaml` — сетевая конфигурация
- `/etc/dhcp/dhcpd.conf` — DHCP-сервер
- `/etc/sysctl.conf` — включение форвардинга
- `firewall.sh` — скрипт управления файрволом
